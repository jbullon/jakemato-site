Free static QR code generator.

Enter a website, generate a QR code, save the image, and leave. This creates a static QR code that points directly to your link.

Need a QR code?

Right-click the QR code and save it, or use the download button.

What this does

  • Creates a static QR code in your browser.
  • Points directly to the URL you enter.
  • Does not create a redirect link.
  • Does not create an account.
  • Does not expire your QR code later.

Want to make one locally with Python?

This website uses JavaScript because GitHub Pages is static hosting. But the same idea works locally with a few lines of Python: 

import qrcode

url = "https://example.com"

img = qrcode.make(url)
img.save("my_qr_code.png")

print("Saved my_qr_code.png")

Install the Python package first: 

pip install qrcode[pil]
